# 3D Portfolio

Scroll-driven 3D portfolio built with React + Three.js (react-three-fiber).

## Run
```bash
npm install
npm run dev
```

## Customise
Edit **`src/data.js`** only — name, role, about, skills, socials, and the project list.
Each project becomes a floating 3D tile (hover → details, drag → spin, click → opens link).

## Deploy
`npm run build` → upload the `dist/` folder to Netlify / Vercel / GitHub Pages.
